BlindNav 复用问题核对，基线 6327cd985200af2aab8e29496a87e5b7526615be。

verify_reuse_findings.py 重新汇总逐组计数，并对所读 _age_cells 方法做函数级合成验证；
它不加载完整工程，不运行 v5/DAV2/SANPO，不代表导航性能改善。
reuse_findings.json 是实际生成结果。
surface_age_incremental.patch 是供独立离线候选试验的最小补丁，不是已应用的生产修复。
该补丁保留原证据衰减率和过期上限，只避免重复衰减同一段时间；不将 UNKNOWN 改成 CLEAR。
它不解决同方向地面/障碍认证缺口；两项修复必须分别对照，不能合并后猜测各自贡献。
补丁对旧证据竞争关系可能有影响，因此实测前不得将其接入真实行走授权。
所有衰减例子均为合成对象，分组计数则来自已提交的历史 E3 CSV；二者不得混为新真实回放。
